# FeeLens 网站重构方案

2026-10-18 · 基于「分析返佣网站流量与安全标记」及运营者补充。

## 定位与范围

FeeLens（费用透镜）是 Mike Xu 运营的独立交易费用与使用指南。第一期聚焦 Backpack，不推广 Toobit；未来按交易所组织内容。品牌名为本次工作名，域名及商标可用性未核验。继续使用 www.backpackref.com，购买新域名后再统一迁移。

用户任务：了解实际成本 → 检查资格和限制 → 了解返佣利益关系 → 前往官方注册。
运营者明确提供：Affiliate 总比例 40%，用户获得交易手续费的 20%，运营者保留 20%。沿用现有 join/meme 链接；后台配置未由本次公开资料独立验证，注册前需核对官方显示。Equity Perps 不适用 Commission Sharing。

## 设计

冷白 #f6f8fc、墨蓝 #172c48、蓝 #315ce7、淡蓝 #e8eefb、绿 #217363。系统 Avenir Next / 中文苹方，正文 16–18px，标题 48–76px。左侧清晰的编辑导语，右侧可操作的费用计算单；用费用分解图作为主视觉，避免模仿交易所交易界面。首页下方是精选 Backpack 研究入口、实用问题与出版者说明。移动端堆叠。

审视：放弃常见的大百分比营销头图与注册按钮矩阵，把可编辑、注明假设的费用计算器放在核心位置。仅返佣页和评测页放官方注册链接，其余先引导理解内容。

## 信息架构

- /en 与 /zh-cn：独立品牌首页
- /review：Backpack 使用评估（优势、限制、决策清单）
- /fees：费用解释与交互计算器
- /referral：20% 手续费分享说明、资格、官方去向
- /tutorial：注册、身份验证与首次入金检查
- /safety：官方域名和账户安全核对
- /faq：高意图常见问题
- /vs-binance：比较方法，避免未经核实的实时排名
- /about、/contact、/affiliate-disclosure、/editorial-policy、/privacy、/terms、/risk-disclosure

## 技术与迁移

保留已有英文/简中文路径。其余七种旧语言逐路径永久重定向至英文（繁中至简中），不发布未维护翻译。生成真实 sitemap、逐页 canonical、hreflang、独立 favicon、分享图与安全响应头。保留 GA 属性但仅用户同意后加载，提供撤回。统一 affiliate link 与 sponsored 属性；点击不视为注册。

## 验收与交付

生产构建、lint、计算边界与路线/SEO/重定向集成检查，桌面与手机视觉验收。提交 GitHub。后续运营：在站长后台核查安全问题、提交 sitemap，依据 Backpack 后台注册/KYC/交易/净佣金验证漏斗；不要用直访次数推断收入。新域名购买及安全标记申诉不属于代码部署本身。
